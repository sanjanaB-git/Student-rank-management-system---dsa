# Student Rank Management System

## About the Project
The Student Rank Management System is a menu-driven application developed using C. It helps manage student records, calculate marks, and determine student ranks.

## Features
- Add student details
- Calculate total marks and percentage
- Rank students based on total marks
- Display all students in a formatted table
- Search students using roll number
- Prevent duplicate roll numbers
- Save and load student records using file handling
- Colorful terminal interface with borders and headings

## Technologies Used
- C Programming
- Structures
- Arrays
- Functions
- Bubble Sort
- File Handling

## How to Compile and Run

Compile the program using GCC:

```bash
gcc student_rank.c -o student_rank.exe
```

Run on Windows PowerShell:

```powershell
.\student_rank.exe
```
